# GitHub topics

Topics are repository settings, not files. Add these in **Settings -> Topics** or with the GitHub CLI when the repository is published.

```
windows
windows-11
windows-10
powershell
gaming
performance
optimization
system-tools
pc-gaming
fps
network
dns
power-plan
maintenance
cleanup
toolkit
open-source
cli
sysadmin
pulse
```

CLI equivalent:

```powershell
gh repo edit --add-topic windows,windows-11,windows-10,powershell,gaming,performance,optimization,system-tools,pc-gaming,fps,network,dns,power-plan,maintenance,cleanup,toolkit,open-source,cli,sysadmin,pulse
```

Machine-readable copy: [`repo-metadata.json`](repo-metadata.json).
